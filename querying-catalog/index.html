    Querying a catalog¶

    A catalog reads a dataset by its key, with no model. This page covers what you can pass to read only the rows and columns you need, from loading the connection to the result.

    If you want the fields and types of the data checked, with Django-style lookups such as amount__gte=100, use a model instead: see Querying models. Lookups need a model to be checked against, so the catalog has only SQL and Polars.

    You write Language Runs on Returns
    load_polars(key, where=..., columns=...) SQL (DuckDB) DuckDB pl.DataFrame
    load_arrow(key, where=..., columns=...) SQL (DuckDB) DuckDB pyarrow.Table
    scan_polars(key, columns=...) then Polars Polars expressions Polars pl.LazyFrame

    From the connection to the data¶

    1. The connection¶

    Connections live in a file (or in Airflow) and are referred to by name:

    # connections.yaml
connections:
  lake:
    conn_type: fs
    extra:
      base_path: /tmp/lake/

    2. The catalog¶

    Each entry says where a dataset lives, in which format, and how it is read and written. This one holds the same data in three formats:

    # catalog.yaml
entries:
  orders_csv:
    file_format: csv
    connection: lake
    location: orders.csv
    load_options: {header: true}
    save_options: {header: true}
  orders_parquet:
    file_format: parquet
    connection: lake
    location: orders.parquet
  orders_delta:
    file_format: delta_table
    connection: lake
    location: orders_delta
    save_options: {mode: overwrite}

    3. Load both and write something¶

    import polars as pl
from smallcat import Connections
from smallcat.catalog import Catalog

connections = Connections.from_yaml("connections.yaml")
catalog = Catalog.from_yaml("catalog.yaml", connections=connections)

catalog.save_polars("orders_parquet", orders)   # orders is a pl.DataFrame

    The examples below read six orders: ids 1 to 6, from customers ada, linus, grace, ada, alan and grace, with the columns id, customer, country, amount, coupon and placed_on.

    load_polars: the whole dataset, or part of it¶

    catalog.load_polars("orders_parquet")

    shape: (6, 6)
┌─────┬──────────┬─────────┬────────┬─────────┬────────────┐
│ id  ┆ customer ┆ country ┆ amount ┆ coupon  ┆ placed_on  │
│ --- ┆ ---      ┆ ---     ┆ ---    ┆ ---     ┆ ---        │
│ i64 ┆ str      ┆ str     ┆ f64    ┆ str     ┆ date       │
╞═════╪══════════╪═════════╪════════╪═════════╪════════════╡
│ 1   ┆ ada      ┆ ES      ┆ 120.0  ┆ null    ┆ 2025-01-10 │
│ 2   ┆ linus    ┆ FI      ┆ 35.5   ┆ WELCOME ┆ 2025-01-21 │
│ 3   ┆ grace    ┆ US      ┆ 980.0  ┆ null    ┆ 2025-02-02 │
│ 4   ┆ ada      ┆ ES      ┆ 15.0   ┆ WELCOME ┆ 2025-02-14 │
│ 5   ┆ alan     ┆ UK      ┆ 240.0  ┆ null    ┆ 2025-03-01 │
│ 6   ┆ grace    ┆ US      ┆ 60.0   ┆ 50%OFF  ┆ 2025-03-09 │
└─────┴──────────┴─────────┴────────┴─────────┴────────────┘

    where: an SQL predicate¶

    where is a single boolean SQL expression (DuckDB) over the dataset's columns. The reader applies it, so on Parquet and Delta only what is needed is read.

    catalog.load_polars("orders_parquet", where="country = 'US' AND amount >= 60")

    shape: (2, 6)
┌─────┬──────────┬─────────┬────────┬────────┬────────────┐
│ id  ┆ customer ┆ country ┆ amount ┆ coupon ┆ placed_on  │
│ --- ┆ ---      ┆ ---     ┆ ---    ┆ ---    ┆ ---        │
│ i64 ┆ str      ┆ str     ┆ f64    ┆ str    ┆ date       │
╞═════╪══════════╪═════════╪════════╪════════╪════════════╡
│ 3   ┆ grace    ┆ US      ┆ 980.0  ┆ null   ┆ 2025-02-02 │
│ 6   ┆ grace    ┆ US      ┆ 60.0   ┆ 50%OFF ┆ 2025-03-09 │
└─────┴──────────┴─────────┴────────┴────────┴────────────┘

    Because it is plain SQL, everything DuckDB accepts in a WHERE works:

    where= Ids
    customer IN ('ada', 'alan') 1, 4, 5
    customer LIKE 'g%' 3, 6
    coupon LIKE '%!%%' ESCAPE '!' 6
    country = 'FI' OR amount > 500 2, 3
    amount BETWEEN 35.5 AND 120 1, 2, 6

    columns: read only some columns¶

    catalog.load_polars(
    "orders_parquet",
    where="amount > 100",
    columns=["id", "customer", "amount"],
)

    shape: (3, 3)
┌─────┬──────────┬────────┐
│ id  ┆ customer ┆ amount │
│ --- ┆ ---      ┆ ---    │
│ i64 ┆ str      ┆ f64    │
╞═════╪══════════╪════════╡
│ 1   ┆ ada      ┆ 120.0  │
│ 3   ┆ grace    ┆ 980.0  │
│ 5   ┆ alan     ┆ 240.0  │
└─────┴──────────┴────────┘

    columns accepts plain column names only, not expressions.

    The same predicate on every format¶

    where does not depend on the format. The three entries hold the same data and give the same rows:

    predicate = "placed_on >= DATE '2025-02-01' AND coupon IS NULL"
for key in ("orders_csv", "orders_parquet", "orders_delta"):
    print(key, sorted(catalog.load_polars(key, where=predicate)["id"].to_list()))

    orders_csv      [3, 5]
orders_parquet  [3, 5]
orders_delta    [3, 5]

    load_arrow: the same, as an Arrow table¶

    table = catalog.load_arrow("orders_delta", where="amount > 100", columns=["id"])
# pyarrow.Table with 3 rows

    scan_polars: Polars expressions, lazily¶

    scan_polars returns a pl.LazyFrame. You filter it with Polars expressions, not SQL, and nothing is read until collect().

    (
    catalog.scan_polars("orders_parquet")
    .filter(pl.col("country").is_in(["ES", "UK"]) & pl.col("coupon").is_null())
    .select("id", "customer", "amount")
    .collect()
)

    shape: (2, 3)
┌─────┬──────────┬────────┐
│ id  ┆ customer ┆ amount │
│ --- ┆ ---      ┆ ---    │
│ i64 ┆ str      ┆ f64    │
╞═════╪══════════╪════════╡
│ 1   ┆ ada      ┆ 120.0  │
│ 5   ┆ alan     ┆ 240.0  │
└─────┴──────────┴────────┘

    On Parquet and Delta the scan is native, so the filter and the columns reach the file scan. Other formats are read in full and then wrapped.

    >>> print(catalog.scan_polars("orders_delta").filter(pl.col("amount") > 100)
...       .select("customer").explain())
simple π 1/1 ["customer"]
  Parquet SCAN [.../orders_delta/part-00000-....snappy.parquet]
  PROJECT 2/6 COLUMNS
  SELECTION: col("amount") > 100.0

    Anything else Polars does can follow, such as aggregating without loading the whole table first:

    (
    catalog.scan_polars("orders_parquet")
    .group_by("country")
    .agg(pl.col("amount").sum().alias("revenue"))
    .sort("revenue", descending=True)
    .collect()
)

    shape: (4, 2)
┌─────────┬─────────┐
│ country ┆ revenue │
│ ---     ┆ ---     │
│ str     ┆ f64     │
╞═════════╪═════════╡
│ US      ┆ 1040.0  │
│ UK      ┆ 240.0   │
│ ES      ┆ 135.0   │
│ FI      ┆ 35.5    │
└─────────┴─────────┘

    Which one to use¶

    • where= when you know the condition as SQL. It works the same on CSV, Excel, Parquet and Delta.
    • scan_polars when you want Polars expressions, a lazy read, or to chain more Polars after the filter. Prefer it on large Parquet or Delta tables.
    • A model when you want the data checked against declared fields and types, or Django-style lookups: see Querying models.

    What is refused¶

    where is parsed before it runs. A statement, a ;, an unbalanced comment, a subquery or anything that changes the shape of the query raises ValueError:

    ValueError: Unsafe or invalid WHERE clause     # 1=1; DROP TABLE data
ValueError: Unsafe or invalid WHERE clause     # id IN (SELECT id FROM read_csv('/etc/passwd'))
ValueError: Unsafe or invalid WHERE clause     # amount >

    SQL is text

    The predicate is checked for shape, not for column names or types, and it is not parametrised: do not build it by pasting user input into the string. If the condition comes from a variable, use a model with lookups, which quote the values for you.

    A key that is not in the catalog raises KeyError.

    The complete script¶

    From the connection to every read above. It writes its files under a temporary directory, and needs nothing but smallcat-chonk.

    pip install smallcat-chonk
python querying_catalog.py

    # ruff: noqa: CPY001, D103, INP001, PLR2004, T201
"""Querying a catalog, from the connection to every way of reading.

Run it with ``python docs/examples/querying_catalog.py``. It writes its
connections file, its catalog and its data under a temporary directory.
"""

import tempfile
from datetime import date
from pathlib import Path

import polars as pl

from smallcat import Connections
from smallcat.catalog import Catalog

workdir = Path(tempfile.mkdtemp(prefix="smallcat-catalog-"))


def title(text: str) -> None:
    print(f"\n=== {text}")


# 1. Load the connection -------------------------------------------------------
(workdir / "connections.yaml").write_text(
    f"""
connections:
  lake:
    conn_type: fs
    extra:
      base_path: {(workdir / "lake").as_posix()}
""",
)
connections = Connections.from_yaml(workdir / "connections.yaml")

# 2. Describe the datasets in a catalog -----------------------------------------
# The same data in three formats: each entry says where it lives and how it is
# read and written.
(workdir / "catalog.yaml").write_text(
    """
entries:
  orders_csv:
    file_format: csv
    connection: lake
    location: orders.csv
    load_options: {header: true}
    save_options: {header: true}
  orders_parquet:
    file_format: parquet
    connection: lake
    location: orders.parquet
  orders_delta:
    file_format: delta_table
    connection: lake
    location: orders_delta
    save_options: {mode: overwrite}
""",
)
catalog = Catalog.from_yaml(workdir / "catalog.yaml", connections=connections)

# 3. Write some data ---------------------------------------------------------------
orders = pl.DataFrame(
    {
        "id": [1, 2, 3, 4, 5, 6],
        "customer": ["ada", "linus", "grace", "ada", "alan", "grace"],
        "country": ["ES", "FI", "US", "ES", "UK", "US"],
        "amount": [120.0, 35.5, 980.0, 15.0, 240.0, 60.0],
        "coupon": [None, "WELCOME", None, "WELCOME", None, "50%OFF"],
        "placed_on": [
            date(2025, 1, 10),
            date(2025, 1, 21),
            date(2025, 2, 2),
            date(2025, 2, 14),
            date(2025, 3, 1),
            date(2025, 3, 9),
        ],
    },
)
for key in ("orders_csv", "orders_parquet", "orders_delta"):
    catalog.save_polars(key, orders)

# 4. Read everything -------------------------------------------------------------------
title("load_polars(): the whole dataset")
print(catalog.load_polars("orders_parquet").sort("id"))

# 5. where= pushes an SQL predicate down to the reader ---------------------------------
title("load_polars(where=...): SQL (DuckDB)")
print(catalog.load_polars("orders_parquet", where="country = 'US' AND amount >= 60"))

title("columns= keeps only some columns")
print(
    catalog.load_polars(
        "orders_parquet",
        where="amount > 100",
        columns=["id", "customer", "amount"],
    ).sort("id"),
)

title("the same predicate works on every format")
predicate = "placed_on >= DATE '2025-02-01' AND coupon IS NULL"
for key in ("orders_csv", "orders_parquet", "orders_delta"):
    ids = sorted(catalog.load_polars(key, where=predicate)["id"].to_list())
    print(f"{key:15}", ids)

title("text, IN, LIKE and OR are plain SQL")
for where in (
    "customer IN ('ada', 'alan')",
    "customer LIKE 'g%'",
    "coupon LIKE '%!%%' ESCAPE '!'",
    "country = 'FI' OR amount > 500",
    "amount BETWEEN 35.5 AND 120",
):
    ids = sorted(catalog.load_polars("orders_parquet", where=where)["id"].to_list())
    print(f"{where:34}", ids)

# 6. Arrow, for tools that speak Arrow -------------------------------------------------
title("load_arrow(): the same, as a pyarrow Table")
table = catalog.load_arrow("orders_delta", where="amount > 100", columns=["id"])
print(type(table).__name__, table.num_rows, "rows")

# 7. scan_polars(): Polars expressions, lazily -----------------------------------------
title("scan_polars(): filter with Polars expressions, nothing is read until collect()")
lazy = (
    catalog.scan_polars("orders_parquet")
    .filter(pl.col("country").is_in(["ES", "UK"]) & pl.col("coupon").is_null())
    .select("id", "customer", "amount")
)
print(lazy.collect())

title("scan_polars() on Parquet and Delta pushes the filter to the file scan")
print(
    catalog.scan_polars("orders_delta")
    .filter(pl.col("amount") > 100)
    .select("customer")
    .explain(),
)

title("scan_polars() then Polars: aggregate without loading everything")
print(
    catalog.scan_polars("orders_parquet")
    .group_by("country")
    .agg(pl.col("amount").sum().alias("revenue"))
    .sort("revenue", descending=True)
    .collect(),
)

# 8. What is refused -------------------------------------------------------------------
title("a where that is not a plain predicate is refused")
for where in (
    "1=1; DROP TABLE data",
    "id IN (SELECT id FROM read_csv('/etc/passwd'))",
    "amount >",
):
    try:
        catalog.load_polars("orders_parquet", where=where)
    except ValueError as error:
        print(f"ValueError: {error}")

title("an unknown key")
try:
    catalog.load_polars("nope")
except KeyError as error:
    print(f"KeyError: {error}")
