    Connect to Amazon S3¶

    A connection to a bucket. It says which bucket, prefix and region to use and how to authenticate.

    # connections.yaml
connections:
  s3_chain:
    conn_type: aws
    extra:
      bucket: my-bucket
      prefix: raw                  # or base_uri: s3://my-bucket/raw
      region_name: eu-west-1

    from smallcat import Connections

conns = Connections.from_yaml("connections.yaml")

    Asking for sales/2024.csv through this connection means s3://my-bucket/raw/sales/2024.csv. s3 is accepted as an alias of aws.

    Which credential¶

    There are two ways, and they cannot be mixed.

    IAM roles and the AWS credential chain (recommended). Leave login and password out, as above. The credentials are found the way the AWS SDK finds them: environment variables, web identity (EKS), ECS task roles, EC2 instance profiles, SSO and the shared AWS files. To assume a role, define a profile with role_arn and source_profile in ~/.aws/config and name it:

    connections:
  s3_profile:
    conn_type: aws
    extra:
      bucket: my-bucket
      profile_name: dev

    Static keys. login is the access key id and password the secret access key, plus aws_session_token for temporary keys:

    connections:
  s3_keys:
    conn_type: aws
    login: AKIA...
    password: <secret-access-key>
    extra:
      bucket: my-bucket
      region_name: eu-west-1

    An S3-compatible store, such as MinIO, takes an endpoint_url:

    connections:
  s3_minio:
    conn_type: aws
    login: minio
    password: <secret>
    extra:
      bucket: my-bucket
      endpoint_url: http://minio:9000

    Validated when loaded¶

    A wrong combination fails when the connections are loaded, with nothing read:

    • login and password must come together.
    • Static keys cannot be combined with profile_name.
    • aws_session_token needs static keys.

    The script below loads these definitions with placeholder keys, so it needs no bucket and no network:

    loaded          Connections(s3_chain:aws, s3_profile:aws, s3_keys:aws, s3_minio:aws)

=== secrets never show up
password        False
get() is plain  example-secret-access-key

=== what is refused, when the connections are loaded
key id without secret  Value error, AWS static keys need both `login` (access key id) and `password`.
keys and a profile     Value error, `profile_name` cannot be combined with static keys (login/password): remove the keys to use the AWS credential chain.
session token only     Value error, `aws_session_token` needs static keys (login/password).

    The secret is not in repr(conns), so it cannot end up in a log.

    Note

    The secrets are plain text in the YAML file. Prefer the credential chain, or load the connections from Airflow (Connections.from_airflow).

    The script¶

    # ruff: noqa: D103, INP001, T201
"""Define connections to Amazon S3, without a network.

Run it with ``python docs/examples/connections_s3.py``. It only loads and
validates the definitions, so it needs no bucket and no credentials: the keys
below are placeholders. Nothing is read or written.
"""

import yaml

from smallcat import Connections
from smallcat.connections_config import ConnectionsValidationError

CONNECTIONS = yaml.safe_load(
    """
connections:
  s3_chain:                       # IAM role / AWS credential chain
    conn_type: aws
    extra:
      bucket: my-bucket
      prefix: raw
      region_name: eu-west-1
  s3_profile:                     # a profile of ~/.aws/config
    conn_type: aws
    extra:
      bucket: my-bucket
      profile_name: dev
  s3_keys:                        # static keys
    conn_type: aws
    login: AKIAEXAMPLEKEYID
    password: example-secret-access-key
    extra:
      bucket: my-bucket
      region_name: eu-west-1
  s3_minio:                       # an S3-compatible store
    conn_type: aws
    login: minio
    password: minio-secret
    extra:
      bucket: my-bucket
      endpoint_url: http://minio:9000
""",
)

conns = Connections.from_dict(CONNECTIONS)
print("loaded         ", conns)

print("\n=== secrets never show up")
print("password       ", "example-secret-access-key" in repr(conns))
print("get() is plain ", conns.get("s3_keys")["password"])  # type: ignore[index]

print("\n=== what is refused, when the connections are loaded")
BAD = {
    "key id without secret": {
        "conn_type": "aws",
        "login": "AKIAEXAMPLEKEYID",
        "extra": {"bucket": "b"},
    },
    "keys and a profile": {
        "conn_type": "aws",
        "login": "AKIAEXAMPLEKEYID",
        "password": "example-secret-access-key",
        "extra": {"bucket": "b", "profile_name": "dev"},
    },
    "session token only": {
        "conn_type": "aws",
        "extra": {"bucket": "b", "aws_session_token": "token"},
    },
}
for label, definition in BAD.items():
    try:
        Connections.from_dict({"connections": {"bad": definition}})
    except ConnectionsValidationError as e:
        reason = str(e).splitlines()[1].strip()
        print(f"{label:22}", reason.removeprefix("- bad: "))

    Run it with python connections_s3.py. See Connections for the loaders and the errors.
