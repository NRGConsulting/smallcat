    Connections with the ORM¶

    How a connection reaches a model: define it once in a file, load it into the registry, and say which connection the model uses when you register it. The model itself never names a connection. It needs nothing but smallcat-chonk; the script writes its files under a temporary directory.

    pip install smallcat-chonk
python connections_orm.py

    1. Define and load the connections¶

    # connections.yaml
connections:
  lake:
    conn_type: fs
    extra:
      base_path: /data
  archive:
    conn_type: fs
    extra:
      base_path: /archive

    from smallcat import Connections

conns = Connections.from_yaml("connections.yaml")

    For a bucket, only this definition changes: see Google Cloud Storage and Amazon S3.

    2. Define the model¶

    from smallcat import Model, ModelFileFormat

class Person(Model):
    id: int
    name: str

    class Meta:
        location = "people.csv"
        file_format = ModelFileFormat.CSV

    3. Load the connections into the registry and register the model¶

    from smallcat import registry

registry.load_connections(conns)
registry.register(Person, connection="lake")

    register is where the connection is chosen, outside the model, so the same model can run against different storage in each environment.

    4. Basic use¶

    import polars as pl
from smallcat import ModelWriteMode

Person.objects.save(df, mode=ModelWriteMode.OVERWRITE)
Person.objects.all()
Person.objects.filter(pl.col("id") > 1).all()

    The script¶

    # ruff: noqa: D101, D103, D106, INP001, T201
"""Load a connection and use it from a model.

Run it with ``python docs/examples/connections_orm.py``. It writes its
connections file and its data under a temporary directory.
"""

import tempfile
from pathlib import Path

import polars as pl

from smallcat import Connections, Model, ModelFileFormat, ModelWriteMode, registry

workdir = Path(tempfile.mkdtemp(prefix="smallcat-conn-orm-"))


def title(text: str) -> None:
    print(f"\n=== {text}")


# 1. The connections: defined once, in a file ----------------------------------
(workdir / "connections.yaml").write_text(
    f"""
connections:
  lake:
    conn_type: fs
    extra:
      base_path: {(workdir / "lake").as_posix()}
  archive:
    conn_type: fs
    extra:
      base_path: {(workdir / "archive").as_posix()}
""",
)
conns = Connections.from_yaml(workdir / "connections.yaml")
print(conns)


# 2. The model never names a connection ----------------------------------------
class Person(Model):
    id: int
    name: str

    class Meta:
        location = "people.csv"
        file_format = ModelFileFormat.CSV


# 3. The registry loads the connections and says which one the model uses ------
registry.load_connections(conns)
registry.register(Person, connection="lake")

# 4. Basic use -----------------------------------------------------------------
title("save and read")
df = pl.DataFrame({"id": [1, 2, 3], "name": ["ada", "linus", "grace"]})
Person.objects.save(df, mode=ModelWriteMode.OVERWRITE)
print("all            ", Person.objects.all().rows())
print("filter         ", Person.objects.filter(pl.col("id") > 1).all().rows())

# 5. Other storage, same model: only the registration changes ------------------
title("the same model on other storage")
registry.register(Person, connection="archive", replace=True)
Person.objects.save(pl.DataFrame({"id": [9], "name": ["alan"]}), mode="overwrite")
print("archive        ", Person.objects.all().rows())
registry.register(Person, connection="lake", replace=True)
print("lake, untouched", Person.objects.all().rows())

# 6. A name that was never loaded ----------------------------------------------
title("a connection that is not loaded")
try:
    registry.register(Person, connection="warehouse", replace=True)
except Exception as e:  # noqa: BLE001
    print(type(e).__name__, "-", e)

    What it prints¶

    Connections(lake:fs, archive:fs)

=== save and read
all             [(1, 'ada'), (2, 'linus'), (3, 'grace')]
filter          [(2, 'linus'), (3, 'grace')]

    The same model on other storage: only the registration changes. Here it is saved to archive and the lake data is left as it was:

    === the same model on other storage
archive         [(9, 'alan')]
lake, untouched [(1, 'ada'), (2, 'linus'), (3, 'grace')]

    Registering against a name that was never loaded fails right away, listing the names that are:

    === a connection that is not loaded
ConnectionNotLoadedError - Connection 'warehouse' is not loaded (available: lake, archive)
